## 常用 Git 命令

```bash
git status          # 查看状态
git add .           # 暂存所有
git commit -m "消息" # 提交
git push            # 推送
git pull            # 拉取
git log --oneline   # 查看历史
```

## 工作流

Reasonix 检测到修改后会主动询问是否提交推送，确认后自动执行。
